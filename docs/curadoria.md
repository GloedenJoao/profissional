## Os critérios, explicitados

1. **Relevância para o que busco** (engenharia de dados, analytics, IA aplicada). Por isso os projetos de dados foram reconstruídos, e não só listados.
2. **Evidência verificável**: testes que rodam, exemplos reproduzíveis, dados sintéticos com resposta conhecida. Um README bonito sem nada executável não entra em destaque.
3. **Processo visível**: histórico de commits, planos, decisões registradas e pivôs explicados. Um projeto inacabado com bom processo vale mais que um "completo" sem rastro.
4. **Nada de dado real**: tudo o que está aqui roda sobre dados sintéticos ou públicos.
